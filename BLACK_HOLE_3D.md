# 3D Black Hole Decoration

The old multi-image "Visual universe" gallery has been replaced with a single decorative
Three.js black-hole scene using `public/blackhole-cinematic.jpg`.

Features:
- Uploaded black-hole artwork used as the visual core
- Real 3D event-horizon sphere and layered rings
- Animated stellar particles
- Gentle floating/rotation motion
- Pointer-controlled 3D parallax
- Responsive WebGL canvas
- Respects the existing Vite/TanStack/Vercel setup

Run:
  npm install
  npm run dev

Build:
  npm run build
